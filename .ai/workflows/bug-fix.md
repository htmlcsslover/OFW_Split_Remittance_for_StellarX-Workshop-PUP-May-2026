# Workflow: Bug Fix

## Process
1. **Reproduction**: Identify the bug and create a minimal reproduction case.
2. **Root Cause Analysis**: Use the **QA Bug Hunter** agent to understand why the bug exists.
3. **Fix Proposal**: Propose a fix that addresses the root cause without introducing regressions.
4. **Implementation**: Apply the fix following the **Senior Full-Stack Builder** guidelines.
5. **Validation**:
   - Verify the fix manually.
   - Add a test case if applicable.
   - Ensure the UI reflects the fix correctly.
6. **Review**: Have the **CTO Architect** or **Stellar Architect** (if blockchain-related) review the change.

## Priorities
1. Security vulnerabilities (Highest).
2. Breaking functionality.
3. UI/UX glitches.
4. Performance issues.
