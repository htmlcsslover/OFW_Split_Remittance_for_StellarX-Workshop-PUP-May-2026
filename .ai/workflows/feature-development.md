# Workflow: Feature Development

## Process
1. **Requirement Gathering**: The **Startup PM** defines the feature's value and requirements.
2. **Design**: The **UI/UX Designer** creates wireframes or UI patterns.
3. **Architectural Review**: The **CTO Architect** and **Stellar Architect** review the technical approach.
4. **Implementation**:
   - Backend/Contract work first.
   - Frontend integration second.
   - UI polishing third.
5. **Testing**: The **QA Bug Hunter** performs exhaustive testing.
6. **Final Review**: The **Hackathon Judge** reviews for demo impact and "wow factor".

## Principles
- **Small Iterations**: Build and test in small, manageable increments.
- **Continuous Feedback**: Check in with the "Judge" agent frequently to ensure alignment with hackathon goals.
- **Documentation**: Update the `.ai/` context if the feature introduces new architecture or rules.
